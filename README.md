# AI Risk Manager

An AI-powered web application built with Streamlit and Google Gemini that analyzes business risks for companies.

## Features

- AI Risk Assessment
- Risk Score Generation
- PDF Report Download
- Excel Report Download
- Report History
- Data Visualization

## Tech Stack

- Python
- Streamlit
- Google Gemini API
- SQLite
- ReportLab
- OpenPyXL
- Matplotlib

## Installation

pip install -r requirements.txt

## Run

streamlit run app.py
